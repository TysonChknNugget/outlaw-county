# Outlaw County

A 2D top-down open-world western crime sandbox set in 1890s Dustwater County, plus its website and a Windows desktop build.

- **Browser game:** `game/index.html` — plain HTML5 Canvas + JavaScript, no engine, no server, no external assets.
- **Website:** `index.html` — landing page with Play Now and Download for Windows.
- **Desktop app:** Electron wrapper in `electron/` that loads the *same* `game/` files.

Everything (pixel art, terrain, buildings, lighting, sound effects and music) is generated by code at runtime.

## Play in a browser

Open `game/index.html` directly (double-click works — no server needed), or open `index.html` and click **Play Now**.
Progress saves to the browser's `localStorage` (3 manual slots + autosave).

## Build the Windows desktop version

Requirements: **Windows 10/11**, **Node.js 18 or newer** (includes npm). An internet connection is needed once to download Electron and electron-builder.

```powershell
npm install
npm run dist
```

`npm run dist` runs electron-builder and then `scripts/publish-download.js`. You get:

- `dist/OutlawCounty-Setup-1.0.0.exe` — installer (choose install folder, desktop + Start-menu shortcuts)
- `dist/OutlawCounty-1.0.0-win-x64.zip` — portable build; unzip and run `Outlaw County.exe`
- both copied into `downloads/`, and `downloads/manifest.js` updated so the website's **Download for Windows** button links straight to the installer.

Other commands:

```powershell
npm start                 # run the desktop app without packaging
npm run build:win         # package only (no copy into downloads/)
npm run publish-download  # copy an existing dist/ build into downloads/
```

The installer is not code-signed, so Windows SmartScreen may show "Windows protected your PC" the first time; choose **More info → Run anyway**, or sign the build with your own certificate (see electron-builder's `win.certificateFile` option).

**Troubleshooting — "Cannot create symbolic link : A required privilege is not held by the client":** electron-builder's signing-tools archive contains macOS symlinks that Windows can't create without admin rights or Developer Mode. Either enable *Settings → System → For developers → Developer Mode* and rerun, or extract the cached archive yourself without the macOS folder and rerun:

```powershell
$c = "$env:LOCALAPPDATA\electron-builder\Cache\winCodeSign"
$a = Get-ChildItem "$c\*.7z" | Select-Object -First 1
node_modules\7zip-bin\win\x64\7za.exe x -y $a.FullName "-o$c\winCodeSign-2.6.0" -xr!darwin
```

Desktop saves live in Electron's `localStorage` under `%APPDATA%\Outlaw County`, and the app works fully offline.

## Publish the website

The site is static files. Upload the whole folder (at minimum `index.html`, `css/`, `js/`, `game/`, `assets/`, `downloads/`) to any static host:

- **GitHub Pages:** push the folder to a repository, then Settings → Pages → deploy from the branch root.
- **Netlify / Cloudflare Pages:** drag-and-drop the folder, or connect the repo with no build command and the root as the publish directory.
- **itch.io:** zip the `game/` folder **together with** `assets/` (keep the same relative layout) and upload it as an HTML game, or link to your hosted site.

If you have built the installer, upload `downloads/OutlawCounty-Setup-1.0.0.exe` (and the ZIP) along with the updated `downloads/manifest.js`. Many static hosts cap single files at around 100 MB; the installer is typically 80–100 MB. If yours is larger than your host allows, upload it as a GitHub Release asset (or similar) and set `windows.file` in `downloads/manifest.js` to that full `https://` URL — the button links to full URLs as-is and to plain filenames inside `downloads/`.

Until an installer is present, the Download button opens a short explanation instead of linking to a missing file.

## Game overview

- **World:** a 320×240-tile county — Dustwater (saloon, sheriff, general store, bank, gunsmith, hotel, stables, chapel, houses, square, station), Mesa Flats, Pinewood Forest with cabins, a pond and the Silverline Mine, the Red Sand Desert with mesas, Rattlesnake camps, abandoned camps and buried treasure, the Sweetwater River and its dry wash, the Iron Horse Railroad with bridges, two stations and a running train, and the Hollister canyon hideout.
- **Crime & law:** witnesses report crimes; five wanted levels; lawmen investigate, search, take cover, call reinforcements and mounted posses, and try to arrest you at low heat. Escape by breaking line of sight, hiding or leaving the area; pay off your bounty at a station or sheriff's office.
- **Economy:** shops, gunsmith, stables (with trade-in), saloon meals and rumors, hotel rooms (sleep + save), train tickets, a fence for stolen goods, a trapper for pelts.
- **Missions:** Outlaw Introduction, General Store Robbery, Stagecoach Ambush, Prisoner Rescue, County Bank Robbery. New missions are added with `MissionSys.register({...})` in `game/js/missions.js`.

## Adding a mission

```js
MissionSys.register({
  id: 'my_job', title: 'My Job', giver: 'boone', giverName: 'Boone Hollister', requires: ['bank'], reward: 200,
  hint: 'Boone has one more job.',
  intro: [{ who: 'Boone Hollister', text: 'Listen close...' }],
  stages: [
    { text: 'Ride to Mesa Flats.', marker: () => ({ x: World.poi.mfStore.x, y: World.poi.mfStore.y, label: 'Mesa Flats' }),
      done: () => nearPlayer(World.poi.mfStore.x, World.poi.mfStore.y, 100) }
  ]
});
```

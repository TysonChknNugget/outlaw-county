# Outlaw County

A 2D top-down open-world western crime sandbox set in 1890s Dustwater County, plus its website and a Windows desktop build.

- **Game:** `game/` — plain HTML5 Canvas + JavaScript, no engine, no server, no external assets.
- **Desktop app:** Electron wrapper in `electron/` that packages `game/` as a Windows app. This is how players get the game — it is download-only.
- **Website:** `index.html` — landing page with Download for Windows. Live at https://tysonchknnugget.github.io/outlaw-county/

The website does not host a playable copy of the game; the Pages workflow publishes only the site files.

Everything (pixel art, terrain, buildings, lighting, sound effects and music) is generated by code at runtime.

## Test the game while developing

Run `npm start` to open the game in the desktop app without packaging it. You can also open `game/index.html` directly in a browser on your own computer for quick testing — that copy is never published.
Progress saves to `localStorage` (3 manual slots + autosave).

## Build the Windows desktop version

Requirements: **Windows 10/11**, **Node.js 18 or newer** (includes npm). An internet connection is needed once to download Electron and electron-builder.

```powershell
npm install
npm run dist
```

`npm run dist` runs electron-builder and then `scripts/publish-download.js`. You get:

- `dist/OutlawCounty-Setup-1.0.0.exe` — installer (choose install folder, desktop + Start-menu shortcuts)
- `dist/OutlawCounty-1.0.0-win-x64.zip` — portable build; unzip and run `Outlaw County.exe`
- both copied into `downloads/`, and `downloads/manifest.js` updated so the website's **Download for Windows** button links straight to the installer.

Other commands:

```powershell
npm start                 # run the desktop app without packaging
npm run build:win         # package only (no copy into downloads/)
npm run publish-download  # copy an existing dist/ build into downloads/
```

The installer is not code-signed, so Windows SmartScreen may show "Windows protected your PC" the first time; choose **More info → Run anyway**, or sign the build with your own certificate (see electron-builder's `win.certificateFile` option).

**Troubleshooting — "Cannot create symbolic link : A required privilege is not held by the client":** electron-builder's signing-tools archive contains macOS symlinks that Windows can't create without admin rights or Developer Mode. Either enable *Settings → System → For developers → Developer Mode* and rerun, or extract the cached archive yourself without the macOS folder and rerun:

```powershell
$c = "$env:LOCALAPPDATA\electron-builder\Cache\winCodeSign"
$a = Get-ChildItem "$c\*.7z" | Select-Object -First 1
node_modules\7zip-bin\win\x64\7za.exe x -y $a.FullName "-o$c\winCodeSign-2.6.0" -xr!darwin
```

Desktop saves live in Electron's `localStorage` under `%APPDATA%\Outlaw County`, and the app works fully offline.

## Release an update (players update automatically)

Installed copies (v1.1.0 and later) check this repository's GitHub Releases when they start and every 3 hours. When a newer version exists, the game downloads it in the background and shows a notice: **Restart & update** saves (when allowed) and installs it; **Later** installs it the next time the player quits. Saves are kept. The portable ZIP can't replace itself, so it shows a "Get the update" button that opens the website instead.

To publish a new version:

1. Raise `"version"` in `package.json` (e.g. `1.1.0` → `1.2.0`).
2. Run `npm run release -- "What changed in this version"`

That builds the installer and ZIP, creates GitHub Release `v<version>` with the installer, ZIP, `latest.yml` and `.blockmap` (the files the updater reads), points the website's Download buttons at the new files, and commits and pushes. It needs the GitHub CLI (`gh`) signed in as the repository owner.

## Publish the website

The site is deployed by `.github/workflows/pages.yml` on every push to `main`. It publishes `index.html`, `css/`, `js/`, `assets/`, `downloads/manifest.js` and the four game scripts the site uses for its live previews (`game/js/util.js`, `data.js`, `world.js`, `sprites.js`). The game page itself is not published.

The Windows builds are attached to a GitHub Release (GitHub won't store files over 100 MB in a repository), and `downloads/manifest.js` points the Download button at the release URLs. For a new version:

```powershell
npm run build:win
gh release create v1.1.0 dist/OutlawCounty-Setup-1.1.0.exe dist/OutlawCounty-1.1.0-win-x64.zip --title "Outlaw County 1.1.0"
```

Then update the version and URLs in `downloads/manifest.js` (and the Portable ZIP link in `index.html`) and push. The button links to full `https://` URLs as-is and to plain filenames inside `downloads/`. If `windows` is `null`, the button opens a short explanation instead of linking to a missing file.

## Game overview

- **Territory (v1.3):** a 1280×960-tile map. The original county sits in the north-west corner, surrounded by six frontier regions in `game/js/world-frontier.js`: the Frostpeak Mountains (Silver Crown), Harlow Lake (Port Harlow), Ranch Country (Fort Granger, Cottonwood Crossing, six ranches), the Red Canyonlands (Rattlesnake Fortress, arches, cliff ruins), the Bonewhite Salt Flats (Hollow Creek ghost town), the Mesa Badlands (Last Water) and the Rio Bravo border (San Lucero). Roads are routed with A* across the terrain. The map has zoom, pan, fog of war and player waypoints.
- **Original county:** a 320×240-tile county — Dustwater (saloon, sheriff, general store, bank, gunsmith, hotel, stables, chapel, houses, square, station), Mesa Flats, Pinewood Forest with cabins, a pond and the Silverline Mine, the Red Sand Desert with mesas, Rattlesnake camps, abandoned camps and buried treasure, the Sweetwater River and its dry wash, the Iron Horse Railroad with bridges, two stations and a running train, and the Hollister canyon hideout.
- **Crime & law:** witnesses report crimes; five wanted levels; lawmen investigate, search, take cover, call reinforcements and mounted posses, and try to arrest you at low heat. Escape by breaking line of sight, hiding or leaving the area; pay off your bounty at a station or sheriff's office.
- **Economy:** shops, gunsmith, stables (with trade-in), saloon meals and rumors, hotel rooms (sleep + save), train tickets, a fence for stolen goods, a trapper for pelts.
- **Story (v2.0):** *What the Ground Remembers*, a prologue, three chapters of seven missions each and a two-part epilogue, with Mara Quill's crew riding at your side. Older saves keep money and gear and restart the story at Chapter 1.
- **Arsenal (v2.0):** 26 weapons including derringer, cap-and-ball, top-break and long-barrel revolvers, a self-loading pistol, brass-frame lever rifle, saddle carbine, buffalo, rolling-block, bolt-action and scoped rifles, double-barrel, sawed-off, pump and semi-auto shotguns, machete, tomahawk, bow with fire arrows and throwing knives, plus mounted crank guns at Fort Granger. Gunsmith upgrades: barrel, grip, sights, engraving.
- **Looks & tailor (v2.0):** townsfolk with their own faces, hair, beards, builds and regional clothes; idle breathing, hit flinches and falling deaths; tailors in Dustwater, Silver Crown, Port Harlow and San Lucero with three saved outfits; changing clothes while wanted is a disguise.
- **Stranger jobs (v2.0):** a stranger in each of seven towns offers replayable jobs: claim jumpers, deliveries, runaway horses, man-eaters, bad debts and escorts.
- **Kingsport (v2.9):** the map is 512 tiles wider (1792×1920). A new east strip in `game/js/world-kingsport.js` holds Kingsport, a port city of 11×15 cobbled blocks and about 280 brick and stone buildings in six districts (Nob Heights, Downtown, the Flats, the Factory District, Riverside and the Waterfront), Union Station on the railroad, piers and tall ships on Kingsport Bay, the Iron Island Penitentiary on its causeway, the Kings River delta, farms on the outskirts, the Tidewater Pines and the fishing village of Gull Harbor. `game/js/kingsport.js` runs the city: blue-coated police with whistles who call reinforcements from street call boxes, horse-car trolleys on two lines ($1 to any stop), two rival gangs (Gaslight Boys in the Flats, Dockside Hooks on the Waterfront) with hideouts and street tolls, boxing at the Ironworks Athletic Club, five-card draw at the Royal Flush Card Room, the opera, the Kingsport Herald's tips, smuggling runs for Fingers Malone, a tailor, and three new heists (Van Doren Jewelers, Ashford Mansion, the rail payroll) beside the Kingsport Trust bank. City art is in `game/js/kingsport-art.js`. No new story. Old saves keep their explored map.
- **Weapon art (v2.9):** `game/js/guns.js` redraws every weapon's icon and the gun in characters' hands. The revolvers and pistols follow the revolver on the skull app icon.
- **Honest work (v2.10):** `game/js/honest.js` adds eight repeatable town jobs with their own mini-games in a shared overlay (`Mini`): bartender (any saloon clerk), blacksmith (any stables), doctor (buy a doctor's bag; patients appear in town), telegraph operator (any station, real Morse code), newspaper photographer (Editor Brennan at the Kingsport Herald sells a camera and hands out assignments), undertaker (carry bodies from town to a church and dig the grave), saloon pianist (rhythm game on D F J K) and Pony Express mail rider (timed rides from any station). `game/js/wild.js` adds trapping, logging (trees really fall and grow back in three days; sell timber at the Kings River Sawmill or float it downriver), herb gathering and tonic brewing at campfires, a wildlife journal (sketch or photograph animals, land fish), six historic treasure maps sold by Professor Finch in Kingsport, selling broken wild horses to the army or the mounted police, and guiding travelers between towns. Each job levels up and pays more; the saddlebags show an Honest Work page. 15 new achievements.
- **Paper map (v2.10):** `game/js/mapart.js` draws the big map as a hand-inked parchment map (coastlines, wave marks, peaks, tree symbols, railroad ties, buildings, compass rose, scale bar). The fog of war is gone.
- **Ride Online (v2.11):** `game/js/online.js` adds peer-to-peer parties of up to 6. One player hosts and gets a code (like `RATTLER-42`); friends type it to join. PeerJS (`game/js/lib/peerjs.min.js`, MIT licence) uses its free public service only to introduce the players, then the games connect directly over WebRTC (the CSP in `game/index.html` allows `0.peerjs.com`). The host's game is the referee for hits, deaths, bounties, arrests and duels. No story online: players choose outlaw, lawman or bounty hunter at any sheriff's office; crimes put a bounty on outlaws, lawmen and hunters knock wanted outlaws down and cuff them for 1.5x the bounty, lawmen lose the badge for shooting an innocent, and any two players can duel for a wager. B opens callouts (no free chat), P the party panel (the host can kick). Online characters are saved in localStorage (`oc-online-char`), apart from story saves. `ONLINE_VERSION` must match between players; keep it equal to the package version.

## Adding a mission

```js
MissionSys.register({
  id: 'my_job', title: 'My Job', giver: 'mara', giverName: 'Mara Quill', requires: ['e2'], reward: 200,
  hint: 'Mara has one more job.',
  intro: [{ who: 'Mara Quill', text: 'Listen close...' }],
  stages: [
    { text: 'Ride to Mesa Flats.', marker: () => ({ x: World.poi.mfStore.x, y: World.poi.mfStore.y, label: 'Mesa Flats' }),
      done: () => nearPlayer(World.poi.mfStore.x, World.poi.mfStore.y, 100) }
  ]
});
```
